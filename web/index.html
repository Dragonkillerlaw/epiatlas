HOW TO READ THIS MAP

Every point has a source.

This map helps you explore published infectious disease reports. The number of reports is not the number of infections. A possible event group is not a confirmed outbreak.

How are points linked to reports?

Reports are grouped by disease, place, and publication dates no more than 45 days apart. You can open each original report. Case and death numbers come from the most recent report in a group that provides usable numbers; cumulative totals across articles are never added together. Locations are matched from text, so a country-level point represents a country, not an exact outbreak address.

What do the colors mean?

The experimental score uses reported case and death counts on logarithmic scales. Thresholds are 25, 50, and 75 out of 100. Missing values can lower the score; gray means there are not enough current numbers or the report describes a resolved or unclear event. This score has not been medically validated and does not measure personal infection risk.

Dates and updates

Filters use publication dates in UTC, not onset dates. The page shows a data snapshot and its last successful collection time. The source repository collects new reports every six hours, but website snapshots require separate publication.
